# Deep Learning — Course Notebooks

Exercises and milestone projects from a deep learning course, covering the core TensorFlow/Keras workflow across data types.

## Covers
- Neural network classification & regression fundamentals
- Convolutional Neural Networks (CV)
- Transfer learning (multiple exercises)
- RNNs, NLP with embeddings, time series
- Milestone projects: **Food Vision** (image classification) and **SkimLit** (NLP for medical abstracts)

## Tech stack
Python · TensorFlow/Keras · Jupyter Notebook
